# Transition examples

Generated by `npm run fixtures` from the same implementation as the CLI:

- [hold-transition.json](hold-transition.json): sequence 1, accepted genesis HOLD.
- [strike-transition.json](strike-transition.json): sequence 20, accepted STRIKE with sequence 19 as predecessor.
- [invalid-transition.json](invalid-transition.json): sequence 1 with a wrong policy commitment and
  disabled simulation-proof flag, rejected by semantic validation.

The STRIKE example requires the preceding record from the
[sample history](../simulator/fixtures/sample-history.json). All three examples
fit the transition schema; structural validity alone does not imply acceptance.
The invalid example also has stale hashes after mutation. These are synthetic
reference records, not on-chain activity or cryptographic proofs.
