# Community code of conduct

Treat contributors and users with respect. Critique ideas and code, explain
disagreements with evidence, and welcome questions. Harassment, discriminatory
language, threats, doxxing, impersonation, and unsolicited financial promotion
are not acceptable in repository discussions, issues, or pull requests.

Maintainers may edit or remove abusive content, close disruptive discussions,
and restrict participation when necessary. Apply these rules consistently and
allow respectful clarification. For conduct concerns, contact a maintainer
through an available GitHub contact channel or use GitHub's reporting tools;
do not post private personal information in a public issue. No separate
moderation contact has been announced.
