# Circuits — planned

There are no implemented circuits, proving keys, verification keys, trusted
setup artifacts, or Groth16 proofs in this directory. The runnable simulator
uses public SHA-256 checksums and must not be described as a ZK system.

[Statement draft](specification.md) records questions for a future implementation.
Groth16 is a proposed research direction, not a shipped dependency or verified
security property. A real implementation needs constraints, encoding rules,
setup provenance, positive and negative vectors, reproducible build artifacts,
and independent review before integration.
