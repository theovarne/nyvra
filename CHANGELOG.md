# Changelog

Changes describe repository contents, not production releases or deployments.

## 0.1.0 — Initial reference implementation

- Typed policy, observation, decision, simulation proof, and transition models.
- Deterministic HOLD / STRIKE evaluation and append-only in-memory history.
- Validation of commitments, decision outcomes, ordering, and predecessor links.
- Runnable seeded CLI simulator and a reproducible 30-record fixture.
- JSON Schemas, accepted and rejected examples, and regression checks.
- Architecture, security boundaries, and planned Groth16 / Solana specifications.
- Repository governance and GitHub Actions validation.

No production agent, ZK circuit, cryptographic proof verifier, or on-chain
program is included. Version 0.1.0 is the package version, not an assertion that
a GitHub release, npm package, or deployment exists.
